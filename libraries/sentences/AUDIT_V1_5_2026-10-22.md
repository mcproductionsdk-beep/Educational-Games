## 3. Confirmed or high-confidence editorial defects

The following examples are from the actual candidate and should be corrected **in content only**. Numbers indicate 1-based position within the topic.

| Priority | Locale / topic / pair | Existing content | Finding and suggested action |
|---|---|---|---|
| **High** | French / Direct object pronouns / 4 | `We need them → Nous en avons besoin` | **Wrong grammar category.** `en` is an adverbial pronoun, not a direct-object pronoun. Replace with `We see them → Nous les voyons`, or move to Y and en. |
| **High** | Italian / Direct object pronouns / 9 | `We watched the film yesterday and liked it → Abbiamo visto il film ieri e ci è piaciuto` | The translation is natural, but `ci` is an indirect experiencer with `piacere`, not a direct-object pronoun. Replace with a sentence using `lo/la/li/le`. |
| **High** | Italian / Past subjunctive / 4 | `He asked us to wait → Ci ha chiesto che aspettassimo` | Marked/unnatural construction in standard Italian. Prefer `Ci ha chiesto di aspettare`, **but** that loses the target subjunctive; replace the example with `He wanted us to wait → Voleva che aspettassimo`. |
| **Medium** | Danish / Reflexive verbs / 7 | `Do you remember the trip? → Kan du huske turen?` | Correct Danish, but **not reflexive**. Replace with `Do you enjoy yourself? → Hygger du dig?` or another reflexive example. |
| **Medium** | Italian / Ci and ne / 4 | `She comes from there → Ne viene` | Possible but decontextualized and unnatural as a standalone beginner example. Prefer a more transparent `ne` example with an explicit antecedent or quantity. |
| **Medium** | French / Y and en pronouns / 5 | `She comes from there → Elle en vient` | Similar context problem: `en` requires a clear prior referent. Prefer an example with an explicit preceding question or context. |
| **Medium** | Spanish / Direct object pronouns / 7 | `She found the keys and gave them to her father → Encontró las llaves y se las dio a su padre` | Valid translation, but adds combined indirect + direct object pronouns. Keep only if application level deliberately permits mixed pronouns; otherwise use a simpler direct-object example. |
| **Medium** | Spanish / Articles and gender / 3 | `The book is interesting → El libro es interesante` | Valid, but topic uses gender/number agreement too. Clarify whether learners are identifying article gender or producing full noun phrases. |
| **Medium** | German / Genitive case / 9 | `The opening hours of the museum are on its website → Die Öffnungszeiten des Museums stehen auf seiner Webseite` | Grammatical, but possessive reference `seiner` adds complexity. Appropriate only with a scaffold; verify target is genitive `des Museums`. |
| **Medium** | Danish / Articles and gender / 9 | `The small child gives the woman a flower → Et lille barn giver kvinden en blomst` | Multiple noun phrases and adjective inflection complicate article-gender focus. Suitable as application only if earlier forms are mastered. |
| **Medium** | French / Imparfait / 4 | `It was raining yesterday → Il pleuvait hier` | Grammatically possible, but isolated `hier` does not establish an ongoing/background past event. Add context (e.g., `when I left`) to make imparfait's aspect clear. |
| **Low** | Italian / Questions / 1–2 | `Where do you live → Dove abiti`; `What are you doing → Che cosa fai` | Existing seed questions lack `?` in both languages. Add punctuation. `Che cosa fai?` is context-dependent (habitual `What do you do?` vs current action); use `Che cosa stai facendo?` for an unambiguous ongoing action. |
| **Low** | Italian / Present tense / 1 | `I eat bread → Mangio pane` | Understandable but bare noun is less natural in some contexts; consider `Mangio del pane` if teaching partitives is appropriate, otherwise retain and note. |
| **Low** | French / Subjunctive / 5 | `We need them to arrive early → Il faut qu'ils arrivent tôt` | Correct paraphrase but changes the subject of necessity and omits explicit `we`. Acceptable for meaning-based tasks, less exact for strict translation tasks. |
| **Low** | Italian / Present subjunctive / 5 | `We need them to arrive early → È necessario che arrivino presto` | Correct paraphrase, but implicit `we`; prefer a prompt without an explicit agent or a closer translation for answer checking. |

These are **documented findings**, not an exhaustive certification that all other 1,092+ entries are error-free. Linguistic judgments are model-assisted and should be verified by proficient educators/native speakers, particularly for Danish, French and Italian.

## 4. Cross-language pedagogical risks

1. **Translation is not one-to-one.** Many English prompts have several equally natural target-language renderings (pronouns, politeness, word order, tense/aspect). Games currently use a single expected sequence; content should prefer prompts with a clear intended answer or support accepted alternatives in a future schema.
2. **Topic drift.** At application level, some examples combine target grammar with unintroduced subordinate clauses or tenses. Flag these for teaching-context review rather than assuming longer = harder.
3. **Stage metadata absent.** The 3 + 3 + 3 scheme is only positional; any randomization or selection of a subset may destroy progression. A future schema should encode stage explicitly, or document that progression is editorial only.
4. **Existing seed sentences preserved.** Original two or nine sentences were retained without full copyediting. Earlier inaccuracies can survive expansion.
5. **No per-sentence provenance or reviewer sign-off.** Store locale, topic, pair index, finding, proposed revision, reviewer and status in a review ledger before production.
6. **Dialect and register.** Spanish uses some European forms, Danish may vary colloquially, and French/Italian subject pronouns and polite forms differ. Decide target classroom register per language.
7. **Sentence assembly ambiguity.** Punctuation, apostrophes, contractions, clitics, and multiword tokens should be checked in each game's tokenizer after any content release. This audit did not run gameplay against the candidate.
8. **Semantic accuracy.** A grammatically sound translation can subtly shift the prompt's meaning. Prioritize close meaning and grammatical focus over literal word-for-word equivalence.
